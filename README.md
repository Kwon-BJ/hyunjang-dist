# 현장지기 — 건설현장 서류 프로그램 (무료)

**현장 서류, 적으면 A4 한 장에 딱.**
공사일보 · 기성청구 · 안전점검 · 위험성평가 · 품질시험 · 공정표를 한 프로그램에서 쓰는 **무료 윈도우 PC 프로그램**입니다.
현장 부장이 실제 현장에서 매일 쓰면서 고쳐 온 프로그램입니다.

### 👉 홈페이지 · 무료 내려받기: **https://kwon-bj.github.io/hyunjang-dist/**

![현장지기 대시보드](https://kwon-bj.github.io/hyunjang-dist/img/dashboard.png)

## 할 수 있는 일

| 업무 | 서류 |
|---|---|
| 공무 | 공사 개요, 기안 · 품의서, 자재 발주서, 발주처 기성청구, 협력업체 기성청구, 계약 대비 기성 |
| 대관 | 문서 · 공문 접수 · 발송 대장, 설계 변경 |
| 공사 | 공사일보(사진 대지 포함), 검측 요청, 공정표, 도면 관리 |
| 안전 | 일일 안전점검, 위험성평가, 안전교육 일지, 산업안전보건관리비 사용내역 |
| 품질 | 시험 · 검사, 부적합 · 재시공, 자재 수불부(입출고) |
| 도구 | 실행내역, 물량산출, 구조계산(비계 · 동바리 · 데크플레이트 등), 자료실 |

## 이런 점이 다릅니다

- **A4 한 장에 딱** — 줄이 늘어도 종이를 넘지 않고, 남으면 빈 줄로 채워 아래가 비지 않습니다.
- **바로 내는 서류 꼴** — 결재란 · 회사 이름 · 사진 대지까지. 인쇄도, PDF 저장도 단추 하나.
- **자료는 내 PC 에** — 사진까지 자료 파일 하나. 백업은 폴더 하나에 늘 최신으로.
- **새 판은 저절로** — 프로그램을 껐다 켜면 새 판이 깔립니다.

## 받는 법

1. 홈페이지의 **[무료 내려받기]** 또는 오른쪽 **Releases** 에서 `hyunjang-setup-(판).exe`
2. 크롬 「일반적으로 다운로드되지 않습니다」 → **보관**, 윈도우 「PC 보호」 → **추가 정보 → 실행** (서명 인증서가 아직 없어 뜨는 말입니다)
3. 처음 켤 때 이름 · 전화번호로 가입 → 승인되면 바로 씁니다

# ASSET_LICENSES — 사용한 재료와 라이선스

이 게임(C:MSWgame)은 오픈소스 게임 **Hedgewars**(https://www.hedgewars.org, 소스 https://github.com/hedgewars/hw, 커밋 3f2a2b6)의
그림·소리·음악을 그대로 가져다 쓴다. Hedgewars 공식 게임이 아니다.

## 참고한 원본 수치 (코드는 옮기지 않고 값만 사용)
| 항목 | 값 | 원본 위치 |
|---|---|---|
| 중력 | 0.0005 px/ms² | hedgewars/uVariables.pas cGravity |
| 최대 바람 | 0.00025, 턴마다 ±랜덤 | uVariables.pas cMaxWindSpeed, uTeams.pas |
| 파워 | 최대 1500ms 누름, 속도=파워/1500 | uConsts.pas cMaxPower/cPowerDivisor, uGearsHedgehog.pas |
| 바주카 | 반경 4, 폭발 50, 바람 영향 | uGearsList.pas, uGearsHandlersMess.pas doStepShell |
| 수류탄 | 반경 5, 탄성 0.8, 마찰 0.8, 타이머 3초(1~5), 폭발 50, 바람 무영향 | uGearsList.pas, uVariables.pas Ammoz |
| 폭발 피해 | min((2R+4-거리)/2, R), 밀려남 0.005*피해+0.01 | uGearsUtils.pas doMakeExplosion |
| 낙하 피해 | dY>0.4 일 때 1+(dY-0.4)*70 | uGearsUtils.pas CheckHHDamage |
| 고슴도치 | 반경 9, 체력 100, 걸음 29ms/1px(6px 오르내림), 사망 시 폭발 30 | uConsts.pas, uGearsList.pas, rust/lib-hwengine-future/src/gear.rs |
| 점프 | 긴 점프(±0.15,-0.15), 높은 점프(-0.2) | rust/lib-hwengine-future/src/gear.rs |
| 턴 | 45초, 발사 후 후퇴 3초 | uVariables.pas cHedgehogTurnTime, Ammoz TimeAfterTurn |
| 팀 색 | 빨강·파랑·청록·보라 | frontend-qt6/hwconsts.h (ClanColorArray) |
